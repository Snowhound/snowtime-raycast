# Snowtime for Raycast

A [Raycast](https://www.raycast.com) extension that starts, stops, and shows your
[Snowtime](https://snowtime.snowhound.eu) timer. What it does and how to set it up is in
[extension/README.md](extension/README.md), which the Raycast Store also shows.

| Path                       | Holds                                                    |
| -------------------------- | -------------------------------------------------------- |
| [extension/](extension/)   | The extension: source, manifest, assets, and npm scripts |
| [docs/](docs/)             | Product scope, development setup, and architecture       |
| [tasks/](tasks/)           | Work items                                               |
| [prototypes/](prototypes/) | HTML prototypes each command is built from               |

Only `extension/` is published to the Store ([publishing](docs/architecture/README.md#repository-and-publishing)).
To work on it, see [docs/development.md](docs/development.md).
