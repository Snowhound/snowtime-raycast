# 009: Lint, test, and build in CI

Status: done

The repository is public, and nothing checks a push or a pull request. A GitHub Actions
workflow at the root, `.github/workflows/`, runs the checks in `extension/`. It sits outside
`extension/`, so `npm run publish` doesn't copy it.

## Acceptance criteria

- [x] A workflow runs `npm ci`, `npm run lint`, `npm run build`, and `npm test` in
      `extension/` on every push to `main` and every pull request
- [x] It uses the Node version `docs/development.md` names
- [x] `npm run build` type-checks (`ray build -e dist`), as `ray build` alone doesn't, and
      `npm test` works on a fresh clone, where `raycast-env.d.ts` is missing
- [x] It passes on `main`, and `docs/development.md` mentions it
