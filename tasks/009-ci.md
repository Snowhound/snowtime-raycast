# 009: Lint, test, and build in CI

Status: todo

The repository is public, and nothing checks a push or a pull request. A GitHub Actions
workflow at the root, `.github/workflows/`, runs the checks in `extension/`. It sits outside
`extension/`, so `npm run publish` doesn't copy it.

## Acceptance criteria

- [ ] A workflow runs `npm ci`, `npm run lint`, `npm test`, and `npm run build` in
      `extension/` on every push to `main` and every pull request
- [ ] It uses the Node version `docs/development.md` names
- [ ] It passes on `main`, and `docs/development.md` mentions it
